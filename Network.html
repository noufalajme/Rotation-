Infrastructure Mind Map

Infrastructure
It is a technical infrastructure that supports all servers and the services running on them, whether internal or external. Even if a service is hosted outside the ministry, using it requires activating key components such as routers, switching, and firewalls.
• Network
• Security
• Infra Systems
Without the infrastructure layer, these components cannot function effectively or securely.
• Handles internal and external (email gateway) communication
• Ensures secure email delivery
• Applies services like:
– Spam filtering
– Data Loss Prevention (DLP)
– Email backups

• Cooling: Air circulation in the room

Network
A core part of the infrastructure department that connects all systems, devices, and services within the ministry. It includes routers, switches and internet connections, enabling secure communication and data transfer between users, servers, and external systems.
Refers to a secure area in MISA’s network that hosts systems needing external access while protecting the internal network.
• Blue Coat Proxy – Filters web traffic
• Forcepoint DLP – Prevents data loss
• FireEye – Detects threats and malware
• Email Filtering – Scans and protects email traffic

Security
Refers to the protection of IT systems and networks in the infrastructure department to prevent, detect, and respond to cyber threats, while ensuring the confidentiality, integrity, and availability (CIA) of data.
• Preventive: Stop attacks before they happen (like firewalls)
• Detective: Discover incidents during or after (like SIEM)
• Corrective: Fix and recover from attacks (like backups)
• Compensating: Alternative control when main one can’t be used
Incoming emails go through a layered security process:
1. Bitdefender checks the reputation of the sender
2. FireEye scans content in a sandbox
3. If clean, the email is passed to Exchange server for delivery
• EDR (Endpoint Detection & Response): Detects threats
• Antivirus software to block malware
• Symantec Endpoint isolates infected devices
• Access is controlled by checking identity and permissions
• NAC checks the device before allowing access
• VPN allows safe connection from outside the ministry
• MDM secures and manages mobile devices
• MAM: Controls access to apps
• MPM: Enforces security rules
• Device Management: Allows only trusted devices
• Adds extra step to login (code from app/phone)
• Prevents access even if password is leaked
• Extra layer of protection for sensitive systems
• Proxy filters web access and blocks harmful websites
• Firewalls apply rules to allow/deny traffic based on content/source
• IPS (Intrusion Prevention System) blocks malicious activity
• DDoS protection defends against overload and shutdown attacks
